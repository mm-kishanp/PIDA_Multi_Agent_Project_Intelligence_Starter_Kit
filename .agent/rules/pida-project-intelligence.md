# PIDA shared project rules

Use the repository-root `AGENTS.md` as the shared operating contract. Inspect existing project guidance before making changes. Verify claims against source code and tests; label findings Verified, Inferred, or Unknown. Maintain `docs/project-intelligence/` and `project-management/` unless the repository has equivalent authoritative files. Implement scoped tasks with acceptance criteria, tests, diff review, and documentation updates. Ask before destructive actions, production deployments, publishing, shared infrastructure changes, or external side effects. Never expose secrets.
